# Aster walkthrough — recording script

**Status:** Script prepared; recording awaits the owner's explicit confirmation of the finished application. No recording has started.

**Application:** [Public Aster demo](https://dashboard-one-rose-14.vercel.app/dashboard). The script follows the deployed frontend workflow, not a mockup. Target length: approximately 3 minutes, with English narration or equivalent readable captions.

## Preparation after recording approval

- Use a clean browser profile with no personal tabs, bookmarks, notifications, or autofill visible. Keep sample-data labeling in frame.
- Open Settings, confirm Reset demo, choose Light, and return to Overview. Use the default last-30-days period throughout.
- Frame desktop at 1440 × 1000 or a comparable readable size. Capture a separate actual mobile view at 390 × 844 for the responsive segment; do not simply shrink a desktop image.
- Use the fictional contact **Jamie Reed**, `jamie.walkthrough@example.com`, source **Paid search**, campaign **Studio Days**. Start with Aurora Studio Headphones showing 42 available units.
- Note the starting paid revenue. The two purchases below must add USD 537, produce two transactions, and leave 39 units. The lead converts once.
- Run through the sequence without recording if needed, then reset again. Keep the finished take's original footage for review.
